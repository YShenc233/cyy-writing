# 公众号文章创作示例

## 示例 1：科技类文章

### 用户输入
"帮我写一篇关于 QClaw 发布的公众号文章，参考这篇腾讯新闻..."

### 阶段 1 输出
**骨架分析**：
- 开头：热点引入（2-3 句）
- 主体：3-4 个要点，每点配案例
- 结尾：总结 + 互动引导

**血肉分析**：
- 用词：简洁有力，避免长句
- 案例：国内科技产品为主
- 数据：如有，需标注来源

**气质分析**：
- 专业但不晦涩
- 适合 25-35 岁科技爱好者

### 阶段 2 输出
A 版：按腾讯新闻结构，平铺直叙
B 版：从开发者视角切入，更有深度

### 阶段 3 Humanize 要点
- 加入"说实话...""不得不说..."等口语
- 长短句交替，避免排比
- 添加个人观点："我觉得这事挺有意思的"

### 阶段 4 HTML 要求
- 标题：18px，黑色，居中
- 正文：14px，#333333，1.8 行距
- 引用：左侧 3px 蓝色边框，浅灰背景
- 重点：红色或加粗

## 示例 2：教程类文章

### 用户输入
"基于这篇教程，帮我写一篇 Cursor 使用指南"

### 阶段 1 输出
**骨架分析**：
- 开头：痛点引入
- 步骤：1-2-3 清晰编号
- 截图/代码块占位
- 结尾：常见问题 + 进阶建议

### 阶段 3 Humanize 要点
- 加入踩坑经历："我第一次用的时候..."
- 用"你"直接对话读者
- 步骤间加过渡："好，接下来..."

---

## Humanize 技巧清单

1. **口语化**：把"因此"换成"所以"，把"然而"换成"但是"
2. **个人化**：加入"我觉得""我认为""说实话"
3. **不完美**：允许短句、断句，不要过度修饰
4. **对话感**：用"你"而不是"读者"
5. **情感词**：加入"挺""蛮""其实"等语气词
6. **长短变化**：避免连续长句，穿插短句
7. **具体化**：用具体例子代替抽象描述
